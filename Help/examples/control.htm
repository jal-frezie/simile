Process Control

This model simulates the behaviour of a widely-used industrial PID controller.  A gas burner is set to maintain the temperature of a water bath at a pre-set level.

 

Process control

Variation

Experiment with tuning the control, by varying the P, Ti, and Td constants.  These are all controlled by sliders in the run-time environment window.  A smaller Ti inclines the controller to over-compensate for errors in the process measurement.  Note the wild swings that result.

Visualisation

A suitable configuration of visualisation tools can be loaded from the file “control.shf”.  The plotter provides a convenient multiple-variable graph comparing temperature with its set point.  The data table provides the numeric values on which the PID controller is operating.
