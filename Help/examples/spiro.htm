Spirograph

A novelty model, this reproduces the Spirograph’s ability to draw complex snowflake-like pictures.  By varying the mechanical settings of the gears holding the pen, a vast variety of repeating patterns can be produced.  In this model, there is no risk of tearing the paper.

 

Spirograph

 

Variation

Experiment with different “Ring”, “Wheel” and “Hole” settings, using the sliders on the “Input sliders” tab.  These variables are:

 

  • Ring = number of teeth on inside of outer ring
  • Wheel = number of teeth on gear that rolls round inside
  • Hole = approx distance of pen from edge of gear

 

For more details on the spirograph, please see http://www.yesterdayland.com/popopedia/shows/toys/ty1379.php. 

Visualisation

A suitable configuration of visualisation tools can be loaded from the file “spiro.shf”.  This uses the XY-plotter to draw the pictures.  Reset (clear) the XY plotter in between each alteration to the sliders.
