delay function

 

delay(var,n)

 

Input:           a variable name and a number (real or integer) of time steps

Result:          the value (real or integer) of the named variable, n time steps ago

 

This function returns some previous value of another variable, a arbitrary period of time before.  The period of time is defined in time steps (not units).  The number need not be an integer, but since time steps are discrete, the effect will always be as if the next largest integer was specified.  The variable whose previous value is required is specified by name.  The variables must be linked with an influence arrow.

 

This is a general replacement for the last( ) function, which returns the value of the named variable from the previous time step only.

 

Examples:

runoff=delay(rain,10)
