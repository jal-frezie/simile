abs function

 

abs(X)

Returns the absolute value of X - i.e. ignores its sign

 

Input:           numeric scalar or numeric array

Result:          numeric scalar or array

 

Examples:

abs(3) --> 3
abs(-3) --> 3
abs([2,-3,4,-5]) --> [2,3,4,5]
