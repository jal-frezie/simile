index function

 

index(I)

Returns the index (instance number) of a member of a fixed membership or population submodel, for the level of submodel nesting specified by the argument.

 

Input:           numeric

Result:          numeric

 

Comment:

The index function is frequently used in conjunction with the element function when working with multiple-instance submodels: both fixed-membership and population submodels.

 

For fixed-membership submodels, the function returns an integer value between 1 and n, where n is the number of instances for the submodel.   For population submodels, it returns an integer between -1 and -n, where n is the total number of instances of the population that have ever existed during this simulation run.  This is not necessarily the same as the number in existence at any point in time, since some instances might have been killed off.
