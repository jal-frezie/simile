New multiple model interface

The behaviour of the "New" and "Open" commands on the File menu have been changed, and a new "Close" command has been introduced. The new behaviour is to allow multiple models to be opened simultaneously in different windows. The "New" command will open a new window, with a blank canvas on which a new model can be created. The "Open" command will load a model (using the normal file dialogue box) into a new window, unless your existing window is blank, in which case it will be used first.

 

The  "New" button on the toolbar has the effect of re-using the existing window for a new model.

 

The "Close" command will close your model (prompting you to save it, if it has changed) and also close the current window unless it is the last window open.

The "Exit" command will close all your models (with prompts to save any modifications) and windows, and exit Simile.

 

Double-clicking on a Simile model in Windows Explorer will open the model in a new Simile window.

 

On building a model, when multiple windows are open, a run control is presented as usual. If multiple models are built, then multiple run controls will be presented. Each run control is associated with one particular model window, and you can use the  "Go to model window" and  "Go to run control" toolbar buttons to move back and forth between the pair.
