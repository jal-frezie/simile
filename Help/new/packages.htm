Packages for easy distribution

Packages are a combination of a model, display configuration and any required parameter specifications. This makes it easy to distribute a model to colleagues.  You can distribute these models to colleagues more easily than sending all the files separately.

 

To create a package, build your model as usual and then save it using the  File...Save command. Then run the model, add the desired displays and the required parameters (if any). Save the display configuration, using the File...Save command on the single-window run time environment. If you are using a parameter file, save it also.

 

Now return to the model window, and use the File...Save package command to create the package. This looks like a normal Simile model, but contains extra parts.

 

To use a packaged model, simply start up Simile and open the package by selecting  File > Open (as for any normal Simile model). When a package is opened all the included parts are loaded, so that the displays are set up and ready to go.

 

If you use the Enterprise Edition, other users can now load and run the packaged model using the free Evaluation Edition.  This is available for download from Simulistics.
