New scripting language

A wholly new scripting language is being introduced in this version of Simile.  The objective is to allow multiple simulation runs to be performed on one or more models, with different parameters, time step settings and so forth for each run, and for the results to be recorded to a text file, for later analysis.  Several different approaches to meeting this need have been considered, including providing a specific graphic interface such as a new run control.  We concluded that scripting allowed the most flexibility and encouraged users to find applications beyond those which we have initially considered.

 

Scripts are written in Tcl/Tk and started using the executable “wish84.exe” in the System/bin directory of the Simile installation.  Use the command “package require SimileAutoObj” to load Simile.
