Lollipop diagram helper

The “Lollipop diagram” is a means of displaying tree-like objects distributed in two dimensions.  Each object has a size, which is used to calculate both the length of the trunk and branches.  After invoking the helper, three variables are required, corresponding to the x-coordinates, the y-coordinates and the sizes.  These can be variables or compartments, and are typically in a multiple-instance submodel.  One tree then corresponds to each instance of the submodel.

 

 

The screen shot shows the default view of the trees.  Clicking on the “aboveBelow” button swaps to an aerial view from directly above the trees.  Some trees may be shading others from view, in which case click the “Swap Z Order” button to bring the hidden trees to the top.

 

Note that all three variables can change through time, so although real-world trees may not move, their graphical representations can.  This means the lollipop diagram helper can also be used for simulating animal movements, and so forth.

 

For best results, the x- and y-coordinates should be scaled between 0 and 100, and the size should be less than 25.
