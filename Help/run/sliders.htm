Sliders for Variable Parameters

This window contains one slider (or switch) for each variable marked as being an “Variable parameter” in the equation dialogue box for that variable.  Note that each slider is scaled individually according to the maximum and minimum values provided in the equation dialogue box..  This information comes from the values for Min and Max entered in the Equation dialogue window.  The initial value for the slider comes from the value entered into the Equation field of that window; if no value is given, then the slider is positioned at the mid-way point.

 

The sliders are positioned by the user to set the value at the start of the simulation.  Once the simulation is running, the sliders can be moved to provide dynamic control over the variable.  The model is updated with the new value in the next time step.  Sliders are grouped by submodel, if possible.

 

To add a display of sliders, use the  sliders toolbar button, or select “Slider control” from the Standard tools submenu on the “Add” menu.  You can add all the variable parameters in the model to the same display, using the sliders toolbar button in the display, or you can add sliders individually, using the  add button.

 

Sliders for Boolean variables are displayed as check-boxes, and do not have minimum and maximum values.
