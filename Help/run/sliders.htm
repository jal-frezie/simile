Sliders for Input Parameters

This window contains one slider (or switch) for each variable marked as being an “Input parameter” in the equation dialogue for that variable.  Note that each slider is scaled individually.  This information comes from the values for Min and Max entered in the Equation dialogue window.  The initial value for the slider comes from the value entered into the Equation field of that window; if no value is given, then the slider is positioned at the mid-way point.

 

The sliders are positioned by the user to set the value at the start of the simulation.  Once the simulation is running, the sliders can be moved to provide dynamic control over the variable.  The model is updated with the new value in the next time step.  Sliders are grouped by submodel, if possible.
