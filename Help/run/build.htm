Running simulations

Preparing a model for running

Simile runs a model by executing a program that it has generated behind the scenes.  This program contains all the instructions need to calculate the values of the model variables as they change over time.  Whenever you want to run the model after making any changes to it, you must re-generate this program.  At the same time, the value of all the variables are calculated ready for the start of the simulation.

 

To build the model, select either the “Run” command in the Model menu, or the “Debug” command.  These generate programs in either of two languages, C++ or Tcl, respectively.  Use the “Debug” command if you have a problem running your model, due to a mathematical error.  You will get a more informative error message. 

 

The Preferences dialogue window, obtained by selecting the Preferences item in the Edit menu, is used to indicate which C++ compiler is to be invoked.  An open source C++ compiler, GNU C, is included in the Simile distribution.  Microsoft Visual C++ is also supported.
