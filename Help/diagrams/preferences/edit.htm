Preferences dialogue box

“Edit” settings

Rectilinear flow routing

Flows can be drawn as either a series of horizontal and vertical sections (following a rectilinear route) or as a straight line (at any angle) between source and sink.  Checking or unchecking this box does not cause the diagram to be redrawn immediately, but when flows are redrawn, they will be redrawn in the new style.  The default is for rectilinear flow routing.

Delete links end-to-end

Influences and other arrows that cross submodel borders are divided into sections.  This option controls whether sections of influence arrows can be deleted individually.  The default is that clicking on a link at any point will delete the whole link.  This alternative, of deleting only the section clicked on, is used to create a slider-controlled variable at each end of the deleted section.
