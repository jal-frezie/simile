Inspect model variable

The snapshot tool is provided to inspect the values of complex data structures held by some model elements.  By hovering over a model variable it is possible to view pop-up windows that contain an elements equation, description and value.  But in some cases, particularly where the data have more than one dimension, this pop-up window is rather hard to read.  In this case, use the snapshot tool.  This will pop-up a larger window with the values structured by dimension.
