Groups of elements

It is often convenient to be able to move or delete a group of elements all at once.  This can be done using the  submodel envelope to group the elements together temporarily, whilst moving or deleting them.  The submodel envelope can be itself deleted afterwards.

 

 Moving a group of elements

  1. Select  submodel tool.
  2. Draw a submodel around the group of components you wish to move.  Note that for this to be possible, the components must have been placed within a rectangular area, within which there are no other components.  For more information on drawing the submodel envelope, see “Adding submodels”.
  3. Select the  move tool
  4. Drag the submodel to move it (and its contents).  Note that for this to be possible, there must be clear canvas with no obstructing elements along the path that you drag the submodel to its destination.
  5. Select the  delete tool.
  6. Delete the submodel boundary.

 

 Deleting a group of elements

  1. Select  submodel tool.
  2. Draw a submodel around the group of components you wish to delete.  Note that for this to be possible, the components must have been placed within a rectangular area, within which there are no other components.  For more information on drawing the submodel envelope, see “Adding submodels”.
  3. Open the submodel into its own window, by double-clicking on its border.  For more informatio, see “Opening a window for a submodel”.
  4. In the newly-opened submodel window, select  new, or use the New command on the File menu, to delete all the components.
  5. Close the submodel window, using the Close command on the File menu.
  6. Select the  delete tool.
  7. Delete the submodel boundary.
