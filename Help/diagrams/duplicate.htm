Duplicating submodels

The “Duplicate submodels” command is used to create an identical copy of a submodel.  There are two alternative procedures to duplicate submodels.

 

  1. Click on the  duplicate submodel symbol on the tool bar.
  2. Click anywhere within the submodel you want to duplicate.
  3. Click in the area of the model diagram where you wish to place the duplicate submodel.
  4. Repeat (2) and (3) if you wish to duplicate other submodels (or the same submodel again).

 

Note that the boundary of the duplicate submodel is created with the same position relative to the click as the original.  For example, if you click in the top left corner of the original submodel, then the click to create the duplicate submodel will also be in its (the duplicate’s) top left corner.  Only if there is sufficient space for the submodel in this position, at the point you click, will it be created.

 

Alternatively,

 

  1. Click on the  duplicate submodel symbol on the tool bar.
  2. Drag from anywhere within the submodel you want to duplicate, to the area of the model diagram where you wish to place the duplicate submodel.
  3. Repeat (2) if you wish to duplicate other submodels (or the same submodel again).

 

Note that an image of the submodel boundary appears whilst you drag.  Only if there is sufficient space for the duplicate submodel at the point you deposit it, will it be created.
