Deleting elements from the model diagram

You use the Delete tool to delete elements from the model diagram.

 

  1. Click on the delete tool.
  2. Move the mouse to the element in the model diagram that you wish to delete.
  3. Click on it to delete it.

 

Please note

For all the tools, selecting the tool puts you into the specified mode.  You remain in this mode until you select another tool.  Therefore, when you have selected the delete tool, you remain in the delete mode until you select another tool.  You must therefore be careful to select another tool when you have finished deleting. 

 

If you should accidentally delete something, then the  Undo tool will bring it back again.

 

Special cases

For most model elements, you click anywhere inside it (in Delete mode) to delete it.

 

To delete a submodel envelope, you click on its boundary, not inside it.  This was a deliberate design decision, since otherwise accidentally missing the element you wished to delete inside a submodel would cause the loss of the whole submodel envelope.

 

To delete a submodel including its contents:

 

  1. Remove the contents of the submodel, by opening up a new window for it, then selecting the  New command from the File menu.
  2. Return to the main Desktop window, select the delete tool, then click on the submodel boundary.

 

You need to be careful when deleting influence arrows, since you may accidentally delete some other model-diagram element instead.  You should be especially careful near to the boundary of a submodel, since you might delete the submodel envelope instead of the influence arrow.

 

Using a submodel envelope (even a temporary one drawn only for this purpose) is a convenient mechanism to delete a group of elements.
