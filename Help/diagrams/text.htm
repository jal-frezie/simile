Adding text

There is limited support for including text on the model diagram.  In particular, a submodel must be used as a placeholder.

 

The following procedure is used to add text.

 

  • Firstly, add a submodel of the desired size and shape, as follows:

 

  1. Click on the  submodel symbol in the tool bar.
  2. Drag the mouse from a blank area of the desktop canvas, corresponding to one corner of the submodel envelope, to the opposite corner of the area that you want to be enclosed in the submodel envelope.
  3. Repeat (2) if you want to add more placeholders.

 

  • Secondly, re-label the submodel.  This is the text you wish to display.  It is most suitable for adding short titles to mark sections of your model.

 

  1. Click on the  select symbol in the tool bar.
  2. Edit the caption as desired.
  3. Click on the  move symbol in the tool bar.
  4. Move the caption to the centre of the placeholder.

 

  • Finally, to size the text as desired, double-click within a blank area within the submodel.  This invokes the submodel properties dialogue box.  Then:

 

  1. Click the “More…” button to view all the available properties.
  2. Slide the “Relative scale” bar to make the text larger or smaller.
  3. Click “OK” to return to the model window.

 

The selected text will now appear in the submodel placeholder.
